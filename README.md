# Rock-Paper-Scissors Game

An interactive, browser-based Rock-Paper-Scissors game featuring real-time score tracking against an automated computer opponent.

---

## Features

- **Interactive Gameplay**: Pick Rock, Paper, or Scissors with instantaneous round resolution.
- **Smart Computer Opponent**: Randomized decision engine for fair play.
- **Live Scoreboard**: Persistent score tracking for both the player and the computer.
- **Visual Feedback**: Distinct win, loss, and tie result messages.

---

## Tech Stack

- **HTML5**: Game board and interactive choice buttons.
- **CSS3**: Stylized buttons, scoreboard layout, and color highlights.
- **JavaScript (ES6+)**: Game loop logic, random choice selection, and score calculation.

---
